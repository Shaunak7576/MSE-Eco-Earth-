# 🌍 EcoEarth - Environmental Awareness Website

A responsive website that promotes environmental protection, sustainability, waste management and eco-friendly habits. It was built as a mid-semester project using **HTML, CSS and basic JavaScript**, with no frameworks or libraries.

## ✨ Features

- **Responsive design** that works on mobile, tablet and desktop
- **Navigation bar** with a hamburger menu on small screens and a highlighted active link
- **Hero section** with call-to-action buttons
- **Animated counters** showing environmental statistics
- **Eco tips section** with category filters (Home, Travel, Food, Shopping)
- **Waste segregation guide** that shows what goes in each bin (Wet, Dry, Hazardous, E-Waste)
- **Eco quiz** with instant feedback and a final score
- **Carbon footprint calculator** that estimates yearly CO₂ emissions
- **Green pledge form** with validation for name, email and action
- **Dark mode** with the theme saved using `localStorage`
- **Back-to-top button** and smooth scrolling
- **Scroll reveal animations** for sections
